# Official Kiroween 2026 requirements verified on 2026-11-09

Sources: [official Devpost rules](https://kiroween.devpost.com/rules), [event home](https://kiroween.devpost.com/), [official FAQ](https://kiroween.devpost.com/details/faqs). These are public event rules, not user-eligibility proof.

- **Submission ends Friday December 4, 2026, 2:00 PM Pacific (PST)** = **Saturday December 5, 2026, 03:30 IST**. The official submission period began October 30, 2026; projects started before that date are **not eligible**. No extension is promised. This timing is operationally important but **this document is not a submission schedule**.
- **Skeleton Crew:** a lean reusable foundation visibly supporting **two distinct applications**, and **two separate application folders in the public GitHub repository**. Our `web/apps/revenant/` and `web/apps/ghost-lap/` satisfy separate app-folder shape when they contain *actual functional source*; ensure they're unambiguously shown with entrypoints and documentation.
- **Root `.kiro/`** must exist in the public repo, not be ignored; real Kiro use must be substantive. **Public GitHub**, open-source LICENSE visible in repo About, functioning app access and accurate run instructions required.
- **Working demo video must be under 3 minutes**. Judging access must be free and maintained through end of judging period (official: January 29, 2027 at 1:00 PM Pacific); never claim a site is deployed until tested.
- **4,000 free credits** request deadline **December 1, 2026 at 12:00 PM Pacific** per official event site/FAQ, if not already obtained. Redeem by December 4; official FAQ states credits expire Dec 31, 2026 11:59 PM Pacific. The task brief describes a 4,000-credit **constraint**, not evidence these credits have already been issued.
- **Student prize eligibility, team size, country/legal-age restrictions** require checking the entrant's actual facts against rules; do not infer eligibility.

Recheck official Devpost rules immediately before submission. No source claims about a particular entrant's account status or actual completed Kiro usage are made here.
