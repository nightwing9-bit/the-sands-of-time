# R7 Option A supported scope

Original Spec 08 called for three learned workloads, including an eight-horizon ML.NET SSA liquidity forecaster. The executed [G4 evaluation](r7-g4-development-gate.md) failed its forecast skill and warning gates. The [G5 drain studies](r7-drain-continuation-gates.md) and [residual SSA study](r7-forecast-learning-gates.md) did not establish useful incremental skill. Their code, reports, evidence formats, and retained local streams and ZIPs remain available for research. None is supported for runtime selection.

Option A preserves the trained R5 fraud model as financially authoritative and makes the genuine G4 SSA–Poisson model available as simulation-evaluated advisory intelligence. Liquidity uses the latest completed seal's posted minus reserved balance at each of eight future seals. This statistical baseline has uncalibrated uncertainty and emits no predictive warning.

The original three-learned-workload claim is unfulfilled. This is an explicit product scope decision; historical specifications and results retain their original meaning. A future learned liquidity method can publish its own versioned evidence behind the existing advisory boundary without changing finance execution. The [R8 handoff](r7-r8-advisory-handoff.md) identifies the supported versions.
