`Hosts.Worker --v4-advisory <execution-uuid> <completed-boundary-ms> [account-id]` returns one account receipt or one receipt per bank. Use `Kind`, `Schema`, `ProducerId`, `PolicyId` and the typed `Anomaly` or `Liquidity` payload. Receipts include the physical `Execution`, root `Lineage`, `Subject`, `Unit`, requested `BoundaryMs` and, when known, `CausalOrigin` (seal boundary, fact sequence, prefix digest) and `SeriesSha256`. Successful receipts include `EvidenceSha256`; only learned receipts carry a model ID and artifact hash. The Worker selects the bundled anomaly pin and the persistence method explicitly; historical context pins cannot select either workload. SSA forecast ZIPs, earlier G3/transfer models and diagnostic G4/G5 artifacts are research only.

Reconstruct with `V4BranchExecution.ReadProjectionHistoryAsync` → `V4ObservationProjector.Project` → the account or bank series at the verified seal. Identical inherited prefixes yield identical canonical series digests and semantic projections/scores; evidence hashes include the physical execution and can differ. After a fork use only that branch's suffix. A child reservation or settlement can change liquidity without changing accepted outgoing-intent counts.

Missing seals, unknown subjects, insufficient history, missing or invalid artifacts and unavailable native runtime have distinct statuses and no score, projection, or successful evidence digest. Retry can recover artifact or runtime failures. Advisory inference is a separate command, with no role in Screening, reservation, settlement or human review. A failed history read or database write is a command failure and returns no successful receipt.

Successful evidence is tenant-scoped and immutable in `revenant.v4_advisory_evidence`; the same bytes at the same key are idempotent. Migration 0015 adds the projection schema. Its existing `model_id` key column holds the method ID for projections, whose canonical bytes contain no ZIP digest. Historical `anomaly-evidence/1`, `anomaly-evidence/2`, `liquidity-forecast-evidence/1` and `liquidity-forecast-evidence/2` retain their formats and original producer semantics.

R8 derives avoided malicious exposure, legitimate delays, false-positive costs and net effects from actual financial branch outcomes and predeclared cost assumptions. Advisory scores and projections supply no dollar savings by themselves.
