# Product invariants

**The Sands Of Time** (former public name Marrow) contains **Revenant** (synthetic financial decisions) and **Ghost Lap** (haunted arena with original solo ghosts). **Marrow** remains the reusable internal foundation. One actual C# Marrow Timeline and one actual React Timeline scrubber must serve both apps. Prioritize visible, verified rewind→restore→fork→compare paths. Source histories/financial ledger are never overwritten by a branch. A historical ghost is noninteractive. The multiplayer C# server owns scores, collision and wins. Complete Phase 1 scope lives in the 13 native specs; do not silently drop social, ML, mobile or auditable finance work. Implementation is **not yet claimed done**.
